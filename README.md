# Eldsoqi Store — متجر إلكتروني (HTML / CSS / JavaScript)

موقع متجر إلكترونيات عربي كامل (RTL) مبني بـ HTML5 + CSS3 + JavaScript خالص، بدون أي مكتبات خارجية أو خطوات بناء.
كل الصور والفيديوهات المستخدمة هي ملفاتك الأصلية، مضغوطة داخل مجلد `assets/`.

> **حجم المشروع الكامل: 17.8 ميجابايت** (أقل من 22 ميجابايت). راجع القسم 8 لتفاصيل الضغط.

```powershell
cd "C:\Users\i9\Desktop\New Eldsoqi Store"
```

## 4) نقاط تحتاج تأكيدك (مهمة)

1. **توزيع صور الأفو:** مجلد `avo-meter` يحتوي 6 صور. تم تقسيمها 3 صور للنوع الأول (290) و3 صور للنوع الثاني (550) اعتمادًا على التشابه البصري فقط، لأن الصور لا تحمل أسماء أنواع. راجع `js/products.js` (السطر `avo-1` و`avo-2`) وبدّل الصور لو التوزيع مختلف.
2. **«بعض العناصر الأخرى»:** الصور الأربع موجودة لكن السعر غير محدد، لذلك البطاقة تظهر بـ«السعر قيد التأكيد» وزر استفسار فقط. عند تحديد السعر أضِف `price` وغيّر `priceStatus` إلى `"confirmed"`.
3. **أسماء الفيديوهات التعليمية:** مستخرجة من أسماء المجلدات — «القدرة في التيار المتردد» (1:33) و«القدرة في الإلكترونيات التناظرية» (6:54). عدّلها من `VIDEOS` في `products.js` إن لزم.
4. **المواصفات:** مكتوبة بشكل عام (الفئة/الاستخدام/طريقة البيع) فقط، ولم تُخترع أي أرقام أو موديلات غير موجودة في أسماء الملفات.

## 5) الميزات المنفّذة

- **السلة:** إضافة/زيادة/تقليل/حذف، دعم المتغيّرات (بريد بورد، مقاومات، ليد)، حفظ دائم في `localStorage` تحت المفتاح `eldsoqi_cart_v1`، عدّاد على الأيقونة، حساب الإجمالي.
- **الطلب عبر واتساب:** اختيار رقم من رقمين (`+20 120 720 6391` أو `+20 111 261 0206`)، ورسالة منسّقة تحتوي الاسم/الهاتف/المحافظة/المدينة/العنوان/الملاحظات + كل منتج (الاسم، المتغيّر، الكمية، السعر) + الإجمالي + عدد القطع + التاريخ. أزرار نسخ الأرقام تعمل مع تنبيه.
- **البحث:** حي أثناء الكتابة، عربي وإنجليزي، مع تطبيع الحروف العربية (أ/إ/آ→ا، ة→ه، ى→ي) وتجاهل التشكيل، اقتراحات في الهيدر، حالة «لا توجد نتائج» مع زر إعادة تعيين.
- **الفلترة والترتيب:** شرائح الأقسام الـ15 بالترتيب المطلوب، ترتيب بالسعر (تصاعدي/تنازلي)، فلترة التوفر (متوفر / الكل)، عدّاد النتائج.
- **العرض السريع:** معرض صور مصغّرة قابلة للتبديل، المواصفات، اختيار المتغيّر وتحديث السعر، إضافة للسلة من داخل النافذة.
- **الفيديوهات:** الفيديوهات التعليمية في قسمها فقط، وفيديوهات المشاريع في قسم المشاريع فقط، مع مشغل مخصص (تشغيل تلقائي عند الفتح، وإفراغ المشغل عند الإغلاق).
- **الوصول (a11y):** إغلاق بـ Escape، إغلاق بالنقر على الخلفية المعتمة خارج النافذة، حصر التركيز داخل النوافذ، إعادة التركيز بعد الإغلاق، سمات ARIA، تسميات بديلة لكل الصور.
- **SEO:** وصف، Open Graph، بيانات JSON-LD، `lang="ar" dir="rtl"`.
